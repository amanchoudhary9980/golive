# GoLive

One click opens OBS, builds the scenes and overlays, checks your mic, and goes live on YouTube.

**[Download the latest installer](https://github.com/amanchoudhary9980/golive/releases/latest/download/GoLive-Setup.exe)** (Windows 10 or 11, 64-bit, about 150 MB)

- Needs OBS Studio 30 or newer. The installer can install it for you.
- Camera is optional: a phone works, or the built-in character stands in.
- Windows may show a SmartScreen warning because the installer isn't code-signed yet. Click **More info → Run anyway**.

This repo only holds the installers. GoLive is a side project, tested on one PC, so expect rough edges. Found a problem? [Open an issue](https://github.com/amanchoudhary9980/golive/issues).
